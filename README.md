# EBCA Membership & Sponsorship

A single-page, mobile-first web app for the **East Bengaluru Cultural Association (EBCA)** — built to help existing and prospective members **join or renew their membership**, and to introduce **sponsorship** opportunities to brands and partners.

## What it does

- **Membership plans** — Solo (₹3,001/year) and Family (₹4,501/year, up to 4 members).
- **Join / Renew form** — a 2-minute flow that validates details and prepares a ready-to-send
  request for the EBCA membership desk via **WhatsApp**, **email**, or **copy-to-clipboard**.
- **Family member details** — optional names for the EBCA celebration wall.
- **Sponsorship section** — impact numbers and four tiers (Shakti, Sanskriti, Mahotsav, Adya Shakti)
  with one-tap enquiry.
- **About / journey, FAQ, and contact** — venue, phone, WhatsApp and email.

Nothing is stored on the page: form submissions open the visitor's own WhatsApp/email app with a
pre-filled message. Payment is completed on EBCA's secure gateway (UPI, cards, net banking).

## Tech

Plain HTML, CSS and vanilla JavaScript in a single `index.html` — no build step, no dependencies.
Hosted with GitHub Pages.
